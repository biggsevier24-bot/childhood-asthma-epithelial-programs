# External ECM sensitivity

Reactome Extracellular Matrix Organization and NABA Core Matrisome are prespecified external sensitivity definitions. They are not inputs to the GSE18965 32-gene derivation. `corrected_external_ECM_pipeline.R` is the recovered corrected pipeline and uses official GSVA ssGSEA only.

The numbered files in this directory document the public interfaces to the recovered analysis; full permutation reruns require the locked random-set membership and standardized matrices listed in the input manifest.
