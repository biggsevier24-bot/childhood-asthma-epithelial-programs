# Hospital cohort analysis interface

This directory exposes model specifications and a table-generation interface. It does not contain, locate, or run protected patient-level data. Frequent exacerbations are defined among the 158 children with prior physician-diagnosed asthma as at least three unplanned-care acute wheeze or dyspnea events in the previous 12 months. Count models require an overdispersion check and a robust Poisson or negative-binomial sensitivity model.
