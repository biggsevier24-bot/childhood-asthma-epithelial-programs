# Protected Hospital Data

The original hospital patient-level data are not included in this public repository because of privacy and ethics restrictions.

De-identified data may be considered by the corresponding author upon reasonable request and institutional ethics approval.

The file `hospital_data_synthetic_example.csv` is fully simulated and is provided only to demonstrate the expected input format. It cannot reproduce the manuscript clinical estimates, odds ratios, incidence-rate ratios, or confidence intervals.
