# Annotation provenance

The candidate universe uses four GO Biological Process terms: extracellular matrix organization (GO:0030198), collagen fibril organization (GO:0030199), wound healing (GO:0042060), and cell adhesion (GO:0007155). Fixed gene memberships were generated with the Bioconductor annotation snapshot recorded in `data/annotation_sources/annotation_sources.tsv`.

Curated families are HGNC collagen, integrin, laminin, and M10 matrix metallopeptidase groups. The matricellular panel is a fixed, literature-derived annotation panel; its dated source snapshot is retained under `data/annotation_sources/`.

Reactome ECM Organization and NABA Core Matrisome are not candidate-selection inputs; they remain external sensitivity definitions.
