# Phenotype Definitions

## GSE18965

- Atopic asthma: manuscript-defined AA group.
- Non-atopic healthy controls: manuscript-defined HN group.
- log2FC: AA minus HN.

## GSE118761

- Nasal epithelium: primary projection tissue.
- Tracheal epithelium: tissue sensitivity projection.
- Asthma and wheeze labels must not be parsed using substring rules that turn non-asthmatic, non-atopic, or non-wheezer labels into positive labels.

## GSE152004

- Molecular T2-high is evaluated using the locked T2 branch described in the manuscript methods.
- T2 score genes: CST1, CLCA1, SERPINB2.
- IFN and repair-ECM scores use fixed gene-set definitions.

## Hospital Cohort

- Full cohort: 325 children.
- Physician-diagnosed asthma: 158 children.
- Clinical T2-high: 162 children.
- Frequent exacerbations: previous 12 months acute wheezing or dyspnea episodes requiring unscheduled medical care, restricted to the physician-diagnosed asthma subgroup.
- Acute exacerbation count includes the index event.
- Regular ICS use before sampling is a sensitivity covariate when available.
