# Audit Rerun Outputs

This folder contains machine-readable outputs from audit or final-locked rerun branches. These files are retained for transparency and code provenance.

Some audit rerun values differ from the final formatted manuscript tables, including hospital model estimates and GSE118761 projection counts. These files must not be described as manuscript source data.

Use `docs/reproducibility_notes.md` and `docs/public_repository_final_audit.md` to interpret the distinction between manuscript-locked outputs and audit reruns.
